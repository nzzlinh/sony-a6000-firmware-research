# Public evidence records

The JSON files in this directory are metadata-only records. They bind a
human-reviewed claim to the hash of the privately analyzed binary and preserve
the REA/Ghidra provenance and limitations.

They intentionally omit decompiler pseudocode, assembly, strings, reference
graphs, basic blocks, native API listings, and native value-flow data. Those
fields may reproduce or closely derive from Sony firmware. Full REA results are
retained outside this repository in the private research archive.

The substantive findings are written in the milestone documents and knowledge
ledger. The records are evidence indexes, not redistributable copies of the
firmware or a license to Sony-derived material.
